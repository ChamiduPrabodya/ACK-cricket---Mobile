# ACK Indoor Cricket Backend

Backend service for the ACK Indoor Cricket application.

## Getting Started

Install dependencies:

```sh
npm install
```

Start the server:

```sh
npm start
```

## Project Structure

- `config/` - application and service configuration
- `controllers/` - request handlers
- `middleware/` - Express middleware
- `models/` - data models
- `routes/` - API route definitions
- `services/` - business and integration services
- `utils/` - shared utility helpers

## Environment

Create a `.env` file in this folder for local configuration. Keep real secret values out of git.
