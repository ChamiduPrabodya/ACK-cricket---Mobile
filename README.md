# ACK Indoor Cricket

ACK Indoor Cricket contains the backend API and the mobile app for the indoor cricket booking application.

## Project Structure

- `backend/` - Node.js and Express backend service
- `frontend/` - Expo React Native mobile application

## Backend

```sh
cd backend
npm install
npm start
```

Create `backend/.env` for local backend configuration. Keep real secret values out of git.

## Mobile App

```sh
cd frontend
npm install
npm start
```

Create `frontend/.env` for local mobile configuration if needed.
